# Module 01 — Basics

## Concepts

- Variables and naming rules
- Data types: `int`, `float`, `str`, `bool`
- Type conversion: `int()`, `float()`, `str()`
- Operators: arithmetic (`+ - * / // % **`), comparison, logical
- f-strings for formatting output

## Practice prompts

1. Store your name and age, print a greeting with both.
2. Convert the string `"42"` to an integer, then to a float.
3. Given `a = 7`, `b = 3`, print sum, difference, product, true division, floor division, and modulus.
4. Evaluate and print: `10 > 5 and 3 < 4`, `not (1 == 2)`.
5. Print `Pi is approximately 3.14` using an f-string with a variable.
