# Module 02 — Control flow

## Concepts

- Boolean expressions
- `if` / `elif` / `else`
- `while` loops
- `for` loops with `range()`
- `break`, `continue`, `pass`
- Nested conditions

## Practice prompts

1. Print `"even"` or `"odd"` for `n = 10`.
2. FizzBuzz for 1–20: multiples of 3 → Fizz, 5 → Buzz, both → FizzBuzz.
3. Sum all numbers from 1 to 100 with a `for` loop.
4. Print numbers 10 down to 1, then `"Liftoff!"`.
5. Ask for input until the user types `quit` (use a `while` loop).
