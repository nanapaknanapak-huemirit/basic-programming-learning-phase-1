# Module 03 — Functions

## Concepts

- Defining functions with `def`
- Parameters and arguments
- Return values vs. printing
- Default arguments
- Scope (local vs global)
- Docstrings

## Practice prompts

1. Write `greet(name)` that returns `"Hello, {name}!"`.
2. Write `add(a, b=0)` that returns the sum; give it a docstring.
3. Write `is_even(n)` returning `True`/`False`.
4. Write `celsius_to_f(c)` using `f = c * 9/5 + 32`.
5. Write `count_vowels(s)` that counts a/e/i/o/u in a string.
