# Basic Programming Learning – Phase 1

![QR code to this site](qr_code.svg)

A beginner-friendly Python curriculum covering programming fundamentals.

## Goals

By the end of Phase 1 you will be able to:

- Work with variables and core data types
- Control program flow with conditionals and loops
- Write and use functions
- Manipulate lists, dictionaries, tuples, and sets
- Read/write files and handle errors
- Solve small programming exercises independently

## Curriculum order

| Module | Topic |
|--------|-------|
| 01 | [Basics]({{ site.baseurl }}/01_basics/) — variables, types, operators |
| 02 | [Control flow]({{ site.baseurl }}/02_control_flow/) — if/else, loops |
| 03 | [Functions]({{ site.baseurl }}/03_functions/) |
| 04 | [Data structures]({{ site.baseurl }}/04_data_structures/) |
| 05 | [Files and errors]({{ site.baseurl }}/05_files_and_errors/) |

Then practice with [exercises]({{ site.baseurl }}/exercises/) and review [notes/cheat_sheet.md]({{ site.baseurl }}/notes/cheat_sheet.md).

## How to use each module

1. Read the module `README.md`
2. Fill in the TODOs in `starters.py`
3. Run your code: `python 01_basics/starters.py`
4. Check your work against the prompts
