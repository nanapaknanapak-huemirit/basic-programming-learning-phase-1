# Little Rainbows Piano

A 12-week, color-coded beginner piano curriculum for children ages 4–6.
Lessons are 30 minutes, once a week, and end with the child playing simple
melodies by color and then by note.

## Quick start

1. Read `00-teacher-guide.md`.
2. Print `printables/piano-printables.html` (A4, portrait, color).
3. Cut out the color cards; use page 2 as the keyboard map and place stickers
   on the keys.
4. Teach `lessons/lesson-01.md` through `lesson-12.md` in order.
5. Send `parent-guide.md` home with the practice card for each lesson.
6. Track progress with `progress-tracker.md`.

## The color system

C red · D orange · E yellow · F green · G blue · A purple · B pink

This matches common Boomwhacker colors, so the same colors can be used with
tuned tubes, bells, or xylophones in group lessons.

## The 12-lesson arc

- **Unit 1 — Explore (1–4):** steady beat, high/low, loud/soft, keyboard map,
  finding C–G, finger numbers.
- **Unit 2 — Colors Make Music (5–8):** two- and three-note color charts,
  quarter and eighth notes, first full melodies, composition.
- **Unit 3 — Colors Become Notes (9–12):** five-line staff, steps and skips,
  color fading to plain notes, two-hand drone, mini recital.

## Print settings

- A4, portrait, 100% scale (do not "fit to page").
- Color printing is required for the first 8 weeks. Pages 6–7 include
  letter-only and shape-only versions for colorblind students.
- Card stock is recommended for the cut-out cards; laminate if reused.

## A note on pacing

The lesson numbers are a guide, not a race. A child who needs two weeks on
"Hot Cross Buns" is doing exactly the right thing. Repeat a lesson whenever
the child is happy and successful, then move on.
